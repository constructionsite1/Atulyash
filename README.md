# Atulyash homepage staging

Three homepage directions for atulyash.com, for review. They are design samples only: sign-in, payment and the PIN check are not connected.

- `a/`: on-brand rebuild with clearer copy, flow and motion
- `b/`: the batch ticket
- `c/`: a morning in the kitchen, as a storybook

`index.html` is the staging page that links all three. Each folder is a static page with its own `app.js` and `img/`, and there is no build step. The site is served with GitHub Pages from `main`.
